# Event Parking Reservation System

Event and Parking Reservation System built using ASP.NET Core Web API with an N-Tier architecture.

## Backend Documentation

The backend API includes authentication, customer management, events, seats, parking, bookings, payments, food court, facilities, and notifications.

API testing was performed using Swagger.
